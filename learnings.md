toml is used to create configuration files for python projects. It prioritizes human readability. It is used to define project metadata, dependencies, and other settings in a structured format.

[] helps us create a table of contents for our project. It helps navigate through different sections of the project documentation easily.

It's main purpose is to provide a clear and organized way to manage project configurations and dependencies, making it easier for developers to understand and maintain the project.

hatchling is a modern, extensible build backend for Python projects. It is designed to simplify the process of building and packaging Python applications. Like for building in JS we use npm, for C we use make, for python we use hatchling. It is a tool that helps developers streamline the development workflow and ensures that projects are built and packaged consistently.
